# Components

All components have been converted from Vue.js to Next.js/React.

## Core Components
- ✅ **AppHeader** - Main navigation header with dropdowns and mobile menu
- ✅ **AppFooter** - Footer with links and social media
- ✅ **AppLoader** - Loading screen component
- ✅ **BaseLayout** - Main layout wrapper
- ✅ **ChatWidget** - Chatbot widget component

## Card Components
- ✅ **AdvertisementCard** - Card for displaying advertisements
- ✅ **NewsCard** - Card for displaying news items
- ✅ **ServiceCard** - Card for displaying services
- ✅ **ProjectCard** - Card for displaying projects
- ✅ **MediaCard** - Card for displaying media items
- ✅ **FlashCard** - Card for flash content
- ✅ **DetailCard** - Card with image and content
- ✅ **RadioCard** - Card for radio content with audio player

## Layout Components
- ✅ **FlashDetailLayout** - Layout for flash detail pages
- ✅ **FlashesCategoryLayout** - Layout for flash category pages

## Notes
- All components use TypeScript
- All components are client components (use 'use client' directive)
- Image components use Next.js Image component for optimization
- Link components use Next.js Link for routing
- All styling matches the original Vue.js version
